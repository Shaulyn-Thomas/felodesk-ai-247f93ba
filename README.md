## Problem Statement

Many workplace tasks can take time when they are done manually, such as writing emails, summarising meeting notes and organising tasks. Felo Desk AI was created to help make these common tasks easier and more organised.

## Solution Overview

Felo Desk AI is an AI-powered workplace productivity assistant. It helps users with common workplace tasks by generating professional emails, summarising meeting notes and organising tasks into a structured plan. Users can review and edit the AI-generated results before using them.

## Prompt Engineering

Prompt engineering was used to give the AI clear instructions and improve the quality of the responses. Prompts were structured using the role, task, context, requirements and expected output. This helps the AI understand what the user needs and provide a more useful response.

## Sample Prompts

### Smart Email Generator
"Write a professional email to my manager asking for leave."

### Meeting Notes Summarizer
"Summarise these meeting notes and list the key decisions and action items."

### AI Task Planner
"Organise these tasks into a weekly plan and prioritise the most important tasks."

## Challenges and Solutions

One challenge was making sure the AI-generated information was clear and useful. The prompts were improved and tested to make the outputs more structured and relevant.

Another challenge was making the application easy to use on different screen sizes. The interface was designed to be responsive so that it can be used on both desktop and mobile devices.

## Project Impact and Value

Felo Desk AI can help users save time when completing common workplace tasks. It can make email writing, meeting summaries and task planning more organised and efficient. The AI outputs can also be edited by the user before they are used.

## Project Status

The main features of Felo Desk AI have been implemented and tested. The application is available as a responsive web application.
